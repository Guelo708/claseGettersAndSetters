# Proyecto: Getters y Setters en Java

Este repositorio contiene los ejercicios realizados en la clase de **Programación Orientada a Objetos** del **14 de febrero de 2026**.  
El objetivo fue practicar el uso de **métodos Getters y Setters** en Java, aplicados a una clase `Cuenta`.

---

##  Estructura del proyecto
- `src/main/java/com/example/Cuenta.java` → Clase principal con atributos privados y métodos Getters/Setters.
- `src/main/java/com/example/Main.java` → Clase con el método `main` para probar la creación y manipulación de objetos `Cuenta`.
- `pom.xml` → Archivo de configuración de Maven.

---

##  Descripción
La clase `Cuenta` incluye:
- Atributos: `saldo`, `idCuenta`, `nombre`, `tipo`.
- Métodos Getters y Setters para cada atributo.
- Método `toString()` para mostrar la información de la cuenta.
- Métodos adicionales como `depositarDinero` y `retirarDinero`.

La clase `Main` crea dos cuentas, asigna valores mediante Setters y prueba operaciones de depósito y retiro.

---

## Ejecución
Se debe clonar el repositorio y ejecutarlo de manera local para repasar de manera detallada lo visto en clase.

## Objetivo de la Clase:

- Comprender cómo funcionan los Getters y Setters.
- Aplicar el concepto de encapsulación básica en Java.
- Practicar la creación de objetos y el uso de métodos en POO.

## Reflexióno o aprendizaje:

Este ejercicio nos permitió conocer:

- La importancia de separar atributos y métodos.
- Cómo los Getters y Setters facilitan el acceso controlado a los datos.
- La utilidad de toString() para imprimir información de manera legible.
